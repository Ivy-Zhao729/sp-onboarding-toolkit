# TFL (Tables, Figures, Listings) Examples

Working examples that generate clinical outputs from CDISCPILOT01 ADaM data.

## Programs

| File | Description | Source |
|---|---|---|
| `t_demog_summary.sas` | Demographics summary table in SAS | ADSL |
| `t_demog_summary.R` | Demographics summary table in R | ADSL |

## Data Source
These programs use the publicly available CDISCPILOT01 ADaM datasets. Download from [CDISC GitHub](https://github.com/cdisc-org/sdtm-adam-pilot-project).
