# Synthetic Source Data

This folder contains small, synthetic (fake) datasets that simulate raw CRF-level data. They are designed to demonstrate SDTM mapping workflows.

These datasets are **not from a real study** — they were created specifically for this toolkit so we can show the full pipeline from raw source data to SDTM.

## Datasets

| File | Description | Maps to SDTM Domain |
|---|---|---|
| `dummy_raw_dm.csv` | Synthetic demographics CRF data | DM |

## Why Synthetic Data?

The CDISCPILOT01 study provides SDTM and ADaM datasets but does not include pre-SDTM source data. To demonstrate the mapping step (raw → SDTM), we created these small synthetic files.

Each file contains 5–10 rows with realistic but completely fictional values.
