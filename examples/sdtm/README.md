# SDTM Mapping Examples

Working examples that map synthetic source data to SDTM domains, following CDISC SDTM IG 3.4.

## Programs

| File | Description | Source | Target |
|---|---|---|---|
| `dm_mapping.sas` | Demographics mapping in SAS | `raw/dummy_raw_dm.csv` | DM |
| `dm_mapping.R` | Demographics mapping in R | `raw/dummy_raw_dm.csv` | DM |

## Data Source
These programs use the synthetic data in `../raw/` and reference the CDISCPILOT01 DM domain structure as the target.
