# ADaM Derivation Examples

Working examples that derive ADaM datasets from CDISCPILOT01 SDTM data, following CDISC ADaM IG 1.3.

## Programs

| File | Description | Source | Target |
|---|---|---|---|
| `adsl_derivation.sas` | Subject-level analysis dataset in SAS | CDISCPILOT01 SDTM | ADSL |
| `adsl_derivation.R` | Subject-level analysis dataset in R | CDISCPILOT01 SDTM | ADSL |

## Data Source
These programs use the publicly available CDISCPILOT01 SDTM datasets. Download from [CDISC GitHub](https://github.com/cdisc-org/sdtm-adam-pilot-project).
